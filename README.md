# ParAly

A private, shared journal for Parth and A.

The first milestone is the notebook experience: a dusty-blue leather cover, silver spiral binding, warm ivory pages, and restrained 3D page turns. The long-term product will add a rich scrapbook editor, shared real-time editing, photo storage, and recoverable version history.

## Development

The app is built with React and Vite. Run `npm install` and `npm run dev` after the application scaffold is added.
